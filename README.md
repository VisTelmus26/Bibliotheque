# Bibliotheque

A weekly index of new design and animation from around the world, shown as a 3D space you move through.

- `index.html`, `style.css`, `app.js`: the site.
- `data/index.json`: the list of weeks and the design and animation types in the menu.
- `data/weeks/<week>.json`: each week's collected pieces.

Each Monday a new week file is added and `data/index.json` is updated.
